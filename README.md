# Starchord Preview builds

This page holds preview builds of **Starchord**, a puzzle game for Android phones, for invited testers.
There is nothing else here: no source code, only the app files and this note.

## Installing the first time

1. On your Android phone, open **Releases** on this page and choose the one marked **Latest**.
2. Tap the file that ends in `.apk` to download it, then open it.
3. Android will ask whether your browser or file app may install apps. Allow it, then tap **Install**.

The app appears as **Starchord Preview**. It is a test build, so Android may show a warning that it does not know the app.

## Updates

When you open Starchord Preview with an internet connection, it looks at this page for a newer preview.
If there is one, it downloads it while the game loads and then asks **Install** or **Later**.

- The first time, Android asks you to allow Starchord Preview to install its own updates.
- The game closes while the update installs. Open it again afterwards. Your progress is kept.
- **Later** means it asks again the next time you open the game.
- Without internet the game plays as usual and simply does not look.

## Privacy

The app reads one small file from this page (`latest.json`) and, when there is a newer preview, downloads it from this page's Releases. It sends nothing about you or your phone: no account, no identifiers, no analytics. As with any website, the servers that host this page see the network address a download comes from.

## Removing it

Uninstall Starchord Preview like any other app. Uninstalling also removes your saved progress in the preview.
